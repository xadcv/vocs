# Internationalisation

Vocs peut servir la documentation dans plusieurs langues. Chaque locale se trouve sous `pages/{locale}/`, et le sélecteur de langue intégré relie les pages équivalentes entre les locales.

Utilisez le sélecteur dans la barre de navigation pour afficher cette page en anglais.
